## 3. Decisions and reasons (details in `docs/DECISIONS.md`)

- Default chat model stays `gpt-5.4-nano`, not `gpt-6-luna` (more reliable on the measured set).
- `gpt-5.4-nano` shuts down 2027-04-01: move to `gpt-6-luna` and set Railway `CHAT_MODEL` explicitly before then.
- KI-025 is fixed by recovery in code, not by prompt wording. Tool-description and system-prompt advice fixed invoices but broke `ru06` and `pb02` and dropped the older set from 77 to 72, so it was reverted.
  A NOT_FOUND for a reference without a file extension is "soft" and cleared by a later successful read. A file-shaped name stays final.
- KI-026 gets exactly one corrective turn, only for a marker that does not exist. A leaked `source_N` handle or UUID, a second bad marker, or no cycle left fails at once.
- A fix is only called fixed after a held-out question set (written and frozen before the fix) and the full suite.
- Gold fixes: `vi06` replaced by `vi08` (its document did answer the question); `id10` accepts either of two files.
- OpenAI spend: never go negative; hard stop at 3.50 USD since the 2026-11-20 top-up (see section 9).

## 8. Invariants to preserve (verified in code)

- Drive access is read-only (`drive.readonly`, `config.py`).
- Every tool query filters on `DriveFile.user_id == context.user_id` and `status == INDEXED` (`app/agents/tool_rag/execution/executor.py`). Two-user tests live in `backend/tests/security/`.
- Citations (`app/agents/tool_rag/finalization.py`):
  - An invented marker is rejected and never repaired by deleting it or adding real ones; one corrective retry only.
  - A leaked handle or id is never retried.
  - Free-form prose after a failed tool is blocked (`provenance_response`).
- The NOT_FOUND hint depends only on the shape of the typed reference, never on whether a file exists (no existence oracle between users).
- Chunk text is authoritative in PostgreSQL; embeddings are in Qdrant under the same chunk UUID, reconciled per file.
- Keep both grounded paths (linear and LangGraph) and the tool-agent path. Chitchat and inventory answers have no citations.
- Never commit secrets. State the cost before every paid run.
- Authentication is in a mixed state. `AGENTS.md` now records exactly which parts are session-scoped and which still use the first stored OAuth token.
